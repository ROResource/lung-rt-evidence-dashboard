Lung cancer · radiotherapy evidence

Survival, local control, toxicity and dose constraints from landmark trials – NSCLC and SCLC, RT alone, SABR, chemo-RT, RT + immunotherapy. Personal reference, not a clinical decision tool.

Figures are author-reported point estimates transcribed from the full text (or the published abstract where tagged “abstract” / “review-sourced”); populations, eras, staging editions, RT techniques and endpoint definitions differ, so cross-trial comparison is indicative only. “Typical range” = span of arm-level estimates across the listed trials for that treatment type – not a meta-analysis, not pooled. Toxicity: compare within a card only (grade threshold, acute/late and grading system are stated per card). Built from the user's full-text library; see README for conventions.
